# Agent team and workflow definitions

## Purpose

These roles are a structured analysis sequence, not claims that separate model processes were run. Give a short finding from each relevant role.

## Roles

1. **Intake:** establish genre, subject, speakers, platform, audience, tone, count, and length; state assumptions.
2. **Transcript:** organise into 10–30 second beats and mark `[LAUGH]`, `[SURPRISE]`, `[STRONG CLAIM]`, `[EMOTION]`, `[QUESTION]`, `[STORY]`, `[DATA]`.
3. **Hook:** rank scroll-stopping openings: claims, questions, tension, surprise, strong reactions, numbers, and curiosity gaps.
4. **Story / structure:** verify hook → build/tension → payoff. Reject anything needing outside context.
5. **Trend:** assign format archetype, audio direction, hashtag cluster, repackaging angle, and timely/evergreen status.
6. **Virality scoring:** score with the rubric in file 02.
7. **Caption and title:** write on-screen hook, captions, hashtags, and Shorts title by platform.
8. **Edit director:** specify in/out, cuts, captions, punch-ins, b-roll, audio direction, and 9:16 framing.
9. **QA:** mark PASS or REVISE; ensure the set is coherent, diverse, brand-safe, and hook-honest.

If the source is too thin for reliable moments, ask for timestamped captions before continuing.
