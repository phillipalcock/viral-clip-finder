# First three seconds

## The promise

By second three, a sound-off stranger must know:

1. who the clip is for;
2. the rough topic; and
3. why they should stay for second four.

If any answer is unclear, the hook has failed.

## Timeline

| Window | Must happen |
|---|---|
| 0.0–0.5s | Visual trigger and text hook are visible from frame one. Use action, result, surprise, or useful incongruity. |
| 0.5–1.5s | Strong spoken line starts already in motion: no breath, greeting, or wind-up. |
| 1.5–3.0s | Context lock: audience and payoff are clear. |

## The four layers

Every hook has all four.

| Layer | Specification |
|---|---|
| Visual | Face mid-sentence, result already visible, screen proof, movement, or reaction. Never a logo, title card, slow pan, or static weak frame. |
| On-screen text | 4–7 words, high contrast, upper-middle, visible from frame one. |
| Spoken line | 10–14 words maximum. Begin on the strong line. Include the primary search keyword if natural. |
| First sound | Voice already talking or a specific relevant sound. Never silence. |

## Patterns to rotate

- Contrarian claim — the opposite of what the audience expects.
- Mistake warning — name a cost already being paid.
- List tease — a countable payoff.
- Curiosity gap — a question the clip answers.
- Direct call-out — name the viewer and their situation.
- Result-first — show outcome, then explain.
- Question on screen — visual question plus spoken answer.
- Mid-action open — cut into the argument, demo, or reaction.

## Hard bans

Reject: “Hey guys”, “Hi everyone”, “In this video”, “Today I want to talk about”; logo stings; intro cards; slow fades; countdowns; irrelevant trending sound; and any clip where the best line begins after second three.

Start on the strongest line. Starting half a second late is better than beginning one second early.

## Workflow

For a chosen source moment:

1. Produce five spoken openers, 10–14 words each, using different patterns. Give no explanation.
2. Select the strongest and write its 4–7 word on-screen version.
3. Specify visual frame one and first sound.
4. Flag the natural search keyword. If none fits, say so rather than forcing it.

For an A/B test, provide two cuts that change only the first 2–3 seconds.

## Placement and test

Place hook text in the central 60%, away from top 120px, bottom 300px, and right 150px. Default: white text with a black outline.

Watch muted before publishing. If the topic, audience, or reason to continue is unclear, rework the opening—not the caption. Fix one layer at a time across a test batch.
