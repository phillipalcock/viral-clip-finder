# Runway steering

Use this only after a clip has been selected and the user wants generated supporting shots, b-roll, or a replacement opening visual.

## Purpose

Create shots that make the first two seconds clearer and improve pacing without faking what happened in the source footage. Generated shots must support the spoken claim, not become bait-and-switch decoration.

## Deliverable

For every requested shot, provide:

- where it appears (timestamp and duration)
- narrative job (hook visual, proof, reset, payoff, loop)
- one concise Runway prompt
- camera/motion instruction
- text-safe area instruction for vertical 9:16
- whether it is safe as b-roll or must be labelled as an illustration/recreation

## Rules

- Start with an image that makes the payoff or tension legible at frame one.
- Generate 1–2 second inserts by default. Long generated b-roll slows the edit.
- Keep subject and action literal where the source makes a factual claim.
- Do not create fabricated documentary evidence, fake screenshots, or synthetic people presented as real participants.
- Keep the centre 60% clear for hook text. Avoid top 15%, bottom 20%, and right-side UI zone.
- When a popular-film reference is used, reference the *energy or visual grammar*, not copyrighted characters, logos, or an exact scene.

## Prompt shape

`Vertical 9:16, [subject] [doing action], [specific setting], [mood], [camera movement], [lighting], practical believable detail, central composition with clean upper-middle text space, no words, no logos.`

## Example

**Job:** frame-one visual for “Most teachers are using AI backwards.”
**Prompt:** `Vertical 9:16, an overstuffed lesson-plan document rapidly collapsing into three clear student checkpoints on a classroom laptop screen, clean modern classroom, quick punch-in camera movement, crisp daylight, central composition with clean upper-middle text space, no words, no logos.`
