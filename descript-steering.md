# Descript steering

Use this file to identify optional Descript work after the main clip ranking. These are suggestions unless a working Descript integration is actually available.

## Rank only material improvements

Offer 3–5 opportunities. Each needs a clear reason it improves retention, clarity, or edit speed. Do not pad the list with generic “add captions” advice.

## Options to assess

1. **Transcript-based rough cut** — delete setup, filler, repeated phrases, and dead air while protecting meaning.
2. **Filler-word and retake pass** — remove ums, false starts, duplicate takes, and long pauses where a jump cut is clean.
3. **Dynamic captions** — create proofread 2–4 word clusters, keyword emphasis, correct names, and safe-zone positioning.
4. **Eye-contact correction** — use only if the original delivery is strong but the speaker repeatedly looks noticeably off-camera; keep it subtle.
5. **Studio sound pass** — reduce noise and level dialogue. Do not over-process a natural voice.
6. **Clip variations** — create two hook versions that differ only in the first 2–3 seconds for an A/B test.
7. **Screen-recording cleanup** — crop, zoom, and call out the exact UI proof while keeping the source legible.

## Output format

For each option provide:

- **Rank + name**
- **Clip it applies to**
- **Why it changes the outcome**
- **Exact Descript operation**
- **Expected lift** — hook, pacing, clarity, accessibility, or workflow speed
- **Risk / guardrail**

Never claim a Descript feature exists or has been run without a connected tool or user confirmation.
