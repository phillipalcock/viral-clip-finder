# Remotion steering

Use this after clips are selected when the user wants a finished editable explainer/edit specification for Remotion.

## Build brief format

Return a practical composition plan, not a vague design description:

1. **Composition name and duration** — 1080×1920, 30 fps unless source needs another rate.
2. **Asset list** — source clip, transcript/captions, optional generated inserts, sound/music.
3. **Timeline** — segments with `start`, `end`, visuals, spoken audio, captions, and transitions.
4. **Caption system** — 2–4 word clusters or word-level emphasis; max two lines; high contrast; one keyword emphasis per cluster.
5. **Frame-one hook** — implement all four layers from `first-three-seconds.md`.
6. **Pacing** — cut filler and pauses; use changes every 3–5 seconds only where they strengthen comprehension.
7. **End loop** — end on a line or visual that naturally returns viewers to the opening.
8. **Export targets** — clean 9:16 MP4, H.264, no platform watermark.

## Transition policy

- **Hard cut:** default; use to increase pace or change thought.
- **J-cut:** let relevant next audio lead a visual shift when it improves comprehension.
- **Whip-pan / speed-ramp:** only if the actual footage contains compatible motion. Do not fake continuity.
- Avoid transition packs, logo stings, fades, and decorative movement in the first three seconds.

## Caption positions

Keep captions away from the top 120px, bottom 300px, and right 150px. Default to centred lower-middle unless a face or key visual occupies that area.

## Quality gate

Before delivery: watch muted; then listen without looking. In both passes, the first three seconds must communicate audience, topic, and reason to continue.
